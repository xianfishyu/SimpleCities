# 发布与验证快照

本目录保留本轮 GitHub 发布及 V4-01 验证时生成的文本资料，作为历史快照随项目提交；当前工单状态以 GitHub 为准。

- `road-system-v4-publish`：22张工单的已发布正文和发布映射。`publication.json` 中的 `complete` 表示该工单的发布与关联流程完成，不表示代码实现完成；`verification.unblockedIssues` 是发布当时的无阻塞工单快照。
- `v4-01-qa`：首张实现票的运行时状态证据、验证摘要和提交说明。临时测试槽位已清理，这些文件仅保留其记录。
- `v4-02-qa`：存档与工具调用方迁移的运行时状态及验证摘要，包含取消、预检失败隔离和正常加载结果。
- `v4-03-qa`：存档协调器收拢的验证摘要和独立Godot进程日志，保留实际后端与桥接不可用的验证边界。

这些快照不承担活动路线图、当前 issue 状态或后续执行队列的职责。

# 发布与验证快照

本目录保留本轮 GitHub 发布及 V4-01 验证时生成的文本资料，作为历史快照随项目提交；当前工单状态以 GitHub 为准。

- `road-system-v4-publish`：22张工单的已发布正文和发布映射。`publication.json` 中的 `complete` 表示该工单的发布与关联流程完成，不表示代码实现完成；`verification.unblockedIssues` 是发布当时的无阻塞工单快照。
- `v4-01-qa`：首张实现票的运行时状态证据、验证摘要和提交说明。临时测试槽位已清理，这些文件仅保留其记录。
- `v4-02-qa`：存档与工具调用方迁移的运行时状态及验证摘要，包含取消、预检失败隔离和正常加载结果。
- `v4-03-qa`：存档协调器收拢的验证摘要和独立Godot进程日志，保留实际后端与桥接不可用的验证边界。
- `v4-04-qa`：独立核心与四档格长空地图的验证记录、真实Vulkan运行日志及地图截图。
- `v4-05-qa`：单条道路建造、类型样式、拾取、保存重载和取消的验证记录与真实Vulkan截图。
- `v4-06-16-qa`：并行推进端点续建与后台操作控制的集成证据，含转弯、类型分界、受控等待、取消和首次绘制计时。
- `v4-07-qa`：共线重叠的精确冲突预览、整笔拒绝、最新请求合并及过期结果隔离验证。
- `v4-08-qa`：主格点十字/T/斜向路口的切分、稳定端接读取、表面归属及保存重载验证。
- `v4-09-qa`：四档格长的格心交叉、对角起建、轴向拒绝、半格重叠及保存重载验证。
- `v4-10-11-qa`：闭环、自环端接及不同路径平行边的核心与真实Vulkan验证，含保存重载、格段预选/拖选、路口分支隔离和格心范围高亮。保留选择契约首次同步读取输入结果失败的日志；等待实际输入分发后，`selection-final.stdout.log` 全部通过，初次失败不作为最终功能结论。

这些快照不承担活动路线图、当前 issue 状态或后续执行队列的职责。

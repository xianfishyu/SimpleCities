# V4 首版限定为米字网格道路

原 V4 指南要求完整迁移六类原生几何，但当前产品需求是方格八方向道路建设，因此将本版交付限定为米字网格直线及多笔相连形成的折线路网。自由角度道路、其他网格和曲线算法不进入本版实现及验收，原曲线设计保留为未来资料，以避免当前重构承担没有对应交互需求的算法与验证范围。该取舍不保证未来增加曲线无需内部调整；重新引入时须重新审定数值、查询、存档和表现契约。

这是已确认的设计决定，不是 V4 已实现的声明；具体规则见[指南 §3](../manuals/road-system-v4-gen.md#3-v4-的范围)，领域用语见[词汇表](../../CONTEXT.md)。

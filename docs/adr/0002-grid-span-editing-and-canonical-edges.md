# 道路格段选择与规范道路边分离

玩家需要按格段删除或改造道路，而规范道路边可能合并跨越多个格段，直接按 Edge 处理会扩大鼠标实际选中的范围。因此保留规范道路边的连续折线模型，以带来源版本的道路位置区间表达选择，按主网格间隔及路口截断，高亮、删除和类型改造共用该作用范围。规划器在私有目标状态中完成必要的切分、删除或类型改变及重新规范化，再一次提交整笔手势，不为每个可选格点永久保留结构节点。

这一决定增加了区间规划的要求，但同时避免了整 Edge 误操作和以交互粒度支配路网存储边界；独立撤销仍以一次有效手势为单位。具体规则见[指南 §4.2](../manuals/road-system-v4-gen.md#42-nodeedge-和端接)和[§6.1](../manuals/road-system-v4-gen.md#61-输入)，领域用语见[词汇表](../../CONTEXT.md)。

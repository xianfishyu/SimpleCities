# Domain Docs

本仓库采用 single-context：根 CONTEXT.md 是领域词汇表，docs/adr/ 保存架构决策。

## 读取规则

- 探索领域代码或编写规格、工单、设计前，读取根 CONTEXT.md 和涉及当前主题的 ADR。
- 文档缺失时继续现有工作；术语或取舍需要落文档时，由 domain-modeling 按需补齐。
- 工单标题、规格、测试名称及设计说明沿用词汇表用语，保持道路格段、格心路口和规范道路边的区分。
- 与已接受 ADR 冲突时明确指出冲突及理由，不静默覆盖原决定。
- 词汇表仅定义领域术语；行为规范、实施安排和测试证据保留在各自文档中。

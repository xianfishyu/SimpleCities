    V4 片段边界计算的重复枚举分配¶

    日期：2026-10-03；生产基线 fe2d383；关联 GitHub #25、road-rendering:BUG-20 证据：.scratch/v4-fragment-bounds-20261003/

    25 米、10K 规范道路边的固定夹具中，单次网格准备的线程托管分配从 32,479,664 B 降至 26,815,992 B，减少 5,663,672 B（约 17.4%）。完整网格指纹、拾取来源和道路显示比例保持。本次局部 Release 对照没有观察到端到端耗时改善，不将分配收益外推为帧率收益。

    定位与实现¶

    上一轮归档的分配栈显示 System.SZArrayHelper.GetEnumerator → Enumerable.MinFloat → V4RoadDisplay..ctor。编辑窗口中有 1,302 个属于该构造器的 Vector2 数组枚举器样本，观测对象大小为 32 B。该跟踪早于生产基线，但其中四个极值查询在 fe2d383 仍未改变；它只提供调用栈线索。本轮另在当前工作树复现分配回归，没有复用旧帧耗时或将采样权重视为精确分配量。

    每个拾取片段原先分别对 X/Y 取 Min/Max，四次通过 IEnumerable 枚举角点数组。改为一次索引遍历，同时维护四个 float 极值；表面预检已经保证数组非空且角点有限。保留原有 0.001 的 double padding、分片插值、片段顺序、空间桶预算和精确多边形拾取规则；没有引入缓存或修改三角化、网格上传、取消及提交边界。

    回归与正确性¶

    在生产修改前，将固定夹具分配门收紧到 26 MiB；旧实现 32,479,664 B 明确失败，修改后 26,815,992 B 通过，门槛未再调整。上传后仍为 143,064 顶点、163,704 索引、44,248 片；SHA256 仍为 ED5D5DC330625ACD11C7E5BC025F8145FF6BE5FFA355556F536BE34DDCEFC013。

    新增八方向长道路的真实 QueryHit 回归：每个方向取 33 个位置，每处检查道路内部三个偏移及外部两个偏移，同时验证来源、EdgeId 和参数。共 1,320 次查询覆盖正负方向、多个空间桶、负坐标和端帽。旧实现上 45 项资源检查通过；修改后这些检查与显示恢复组合共 112 项通过。

    • Core 376/376、Application 968/968。初次完整运行中，一项已有线程身份测试失败；已由独立提交 612292f 修正运行前提，保留全部断言，相关 28 项连续五轮通过、所属 Application 套件完整通过。见 test-infrastructure:BUG-1，未将初次失败改写为通过。
    • Debug/ExportRelease 的 .NET 构建均 0 警告/错误；Roslyn 重建五项目后编译器/分析器诊断为空。
    • 五套容量 159 项/46 次操作通过；编辑器 100 米 10K 的 45 项资源、35 项交互检查及 10 次操作通过，截图已目视。
    • 运行中的 MCP 读取到了本次通过输出，stderr 为空。直接 DAP 也捕获相同场景结果，但早期 attach 因尚未运行返回 not_running，保留该响应，不声明所有 DAP 操作成功。

    GDScript LSP 返回空诊断，但编辑器先后两次记录“Client is opening already opened file”，串行复核仍出现，具体文档/请求成因未定位。此工具的无错门保留限制；实际脚本加载、资源与交互结果独立通过。导出日志仍包含与基线相同的未识别 UID、MCP 端口占用和 ImGui GDExtension 加载错误；导出产物生成成功、两个 DLL 均为优化配置，实际 Release 游戏错误检查通过。没有把这些工具日志归为道路行为错误或隐去。

    同条件 Release 局部对照¶

    真实 Vulkan Forward+、1600×900、Dummy 音频、VSync 与帧上限关闭，25 米 10K、预热 5 秒、四类输入窗口各 2 秒、10 轮编辑/建造/历史和 20 次立即取消。用户确认桌面可用后连续运行两组，未并行构建、测试或其他基准。

    两版各 191 项检查、120 次测量操作通过。原生 self 分别 282/278，other 均为 0；二进制哈希、退出码、运行日志、逐帧焦点、原生 PID/句柄、轮询间隔和启动期附加释放均核验。

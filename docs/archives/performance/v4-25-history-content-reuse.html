    V4 相邻撤销与重做的内容重用¶

    日期：2026-10-04；关联 GitHub #25、#26；优化前检查点 c11f2a8f。 原始证据：.scratch/v4-completion-20261004/；产品决定见 历史策略。

    变更与资源边界¶

    以前 Undo/Redo 即使恢复刚显示过的完整内容，仍重建核心查询数据、比较全图变更、生成路面、准备拾取索引并上传新 ArrayMesh。此前分配分析已发现大量大对象分配触发的 Gen2 GC，数次局部优化后仍有明显长帧。

    现在 RoadNetwork 只以弱引用记住前一个已提交快照；如果仍有显示或读取方持有相同 network/lineage/content revision/map，则重用不可变 Nodes/Edges/QueryData，并创建新发布 token、ChangeSequence 和单调不回退的 ID watermark。历史回放从记录的 delta 构造正确方向的变更列表，不重新比较全图。弱引用失效或目标不匹配时仍走原来的重建路径，历史本身不持有派生索引或完整快照。

    V4MapView 稳态仅持有当前显示和前一幅成功显示。后台命中同一不可变实体集合时跳过表面和几何重建；主线程上传步骤创建绑定新快照的显示包装并取得已有网格的共享所有权。所有拾取结果重新绑定新 token，旧位置不能用于新发布。准备候选期间没有引擎资源租约，取消、候选丢弃及场景退出不会遗留它的租约。

    缓存和首次绘制回退各有一个明确位置：新显示成功绘制才淘汰旧缓存，前一显示成为缓存。转换期间最多存在三份显示包装；相同内容共享网格。缓存淘汰只释放自身的所有权，最后一个所有者释放网格。加载的新 lineage、新地图和退出场景释放旧缓存。资源预检、发布、首次绘制失败仍遵守原有核心/历史提交边界和整幅旧画面回退。

    这是以额外保留一幅完整显示换取相邻历史重放速度的有界缓存；多步连续撤销、普通新编辑或缓存失效仍可能全图重建。没有把 64 笔历史变成 64 份派生缓存，也没有改变道路的虚拟宽度比例、GC 配置或性能门槛。

    回归证据¶

    • 核心公开测试先红后绿：240 边已观察快照的撤销计划由 239,576 B 降至 744 B，保持 <16 KiB 断言。覆盖新 token、旧位置失效、内容恢复和 Undo/Redo；弱引用回收后原重建回放仍正确。最初弱引用测试持有 setup plan 的生命周期错误已在测试辅助函数中修正，不将其称为生产泄漏。
    • 真实 Godot 25 米/10K：撤销核心计划加重用显示准备 872 B，主线程重用步骤 0 B；ArrayMesh 为同一个实例，发布 token 更新。计数不包含 UI、任务调度、首次完整准备或进程资源，不作为每帧/整个操作零分配声明。
    • v4_history_reuse_runtime_contract.gd 93 项通过：包括新版本拾取/拖选、旧位置拒绝、共享资源释放、失效候选、取消、历史分支、缓存命中时的预检/发布/首帧故障与重试、新地图及退出清理。原 v4_display_retry_runtime_contract.gd 112 项通过；五套容量场景 159 项/46 次操作通过。
    • Core 383/383；Application 初跑因新 QA 资源未排除失败 1 项，补齐导出过滤后 968/968。Debug 与 ExportRelease build 均 0 警告、0 错误；改动 C# 文件 Roslyn diagnostics 和全方案 compiler/analyzer diagnostics 为空。新的探针仅编入 Debug。
    • 首次新 GDScript 测试使用 free() 释放 RefCounted 导致脚本中断，已改为释放引用并完整复跑成功，保留失败日志。容量脚本默认输出曾写入旧证据目录；本轮产物已转存到当前证据目录，旧受控文件恢复原提交内容。

    无跟踪 Release 对照¶

    顺序旧→新→新→旧。25 米/10K、1600×900 Vulkan Forward+、Dummy 音频、默认 GC、VSync/帧率限制关闭；预热 5 秒，四个基础窗口各 1 秒，5 轮共 60 次有效操作（15 次新编辑、45 次相邻 Undo/Redo），20 次取消及 1 秒结束空闲。四组 EXE/程序集/数据集哈希、优化配置、进程退出、运行时检查、完整前台窗口和全部帧统计由 compare-reuse.py 复验。

    历史交互显著改善，超预算帧数也减少；普通编辑没有稳定改善，最大长帧仍约 62 ms。全部操作响应 P95 新版约 123–124 ms，高于旧版约 106 ms，不能把历史操作收益推广到普通编辑，也不能据短窗口宣布稳定 144 FPS。需继续处理缓存未命中的全图准备和上传路径。

    80 次取消均保持活动状态不变，已记录时延未超过 10/100 ms 警戒线；新版取消样本的 worker 延迟全部被现有计量记为 0，可能是 worker 已结束、尚未回到主线程的竞态，不作为在深度计算阶段及时退出的证明。#26 仍需补充明确分类和重复释放证据。

    未完成的门¶

    本会话无 godot / godot-minimal MCP；真实独立 Godot 和 Release 证据不替代编辑器输入、增量编辑器日志或 DAP。导出进程退出 0、优化程序集身份正确，但日志保留 ImGui GDExtension 加载错误、本轮启动时主场景 UID 未识别及 Godot MCP 6550 端口占用错误；该 UID 与 Scenes/MapTest.tscn 一致，用户编辑器仍保持运行，未重配或关闭它。实际测试及导出游戏日志没有这些错误。

    V4 固定尺寸面板的字体首次使用卡顿¶

    日期：2026-10-03；关联 GitHub #25。 修复前实现检查点 e8be555b；各导出包的构建时提交与文件哈希见其 source manifest。 证据：.scratch/v4-font-first-use-20261003/。 UI 修复记录：ui:BUG-17。

    本轮定位并修复了帧时间线报告中重复出现的首次删除长帧。V4 面板继承项目的默认 FontFile，其 multichannel_signed_distance_field=true；新工具文字首次绘制时生成尚未缓存的 MSDF 字形。该面板处于 CanvasLayer，保持屏幕像素尺寸，不随道路相机缩放，当前 UI 不需要按世界缩放的距离场字形。

    V4MapScene.InitializeHudFont() 在面板初始化时复制实际继承的字体，关闭副本的 MSDF，并只分配给 HUD/Panel 的局部主题。字体家族、字号和系统中文回退保留；全局字体、其他场景、道路与背景网格不变。没有将删除动作提前执行，也没有把字体预热加入正式性能脚本以移出长帧。

    因果对照¶

    先在空地图中仅切换改造/删除工具文字，不建造或编辑道路、不启动工作线程。探针先留下一次帧末锚点，再记录包含切换的下一帧，避免漏掉首次调用。

    空地图实验 首次改造窗口最大 ms 首次删除窗口最大 ms
    原字体，冷启动 27.645 11.584
    仅提前绘制删除帮助文字 25.345 5.451
    复制原字体但保留 MSDF 27.885 12.302
    字体副本关闭 MSDF 3.777 1.935
    字体副本关闭 MSDF，重复 4.336 1.969

    仅字体绘制的预热调用耗时 11.771 ms，记录在采样前的独立字段，未当作正式修复；复制且保留 MSDF 的控制组排除了单纯创建新主题/字体副本的解释。五组真实 Vulkan 重放均通过状态不变检查和原生前台验证。这将重复卡顿定位到字体首次使用，与此前 GC 请求无交集及处理→绘制前区间的证据一致；不用于解释所有其他长帧。

    10K 道路 Release 复验¶

    修复前后使用优化 ExportRelease、同一个 25 米/10,000 条规范道路边夹具、1600×900、Vulkan Forward+、Dummy 音频；项目默认 GC、不覆盖堆数、不限制 FPS、关闭 VSync。每组预热 5 秒、四个基础窗口各 1 秒、5 轮改造/删除/建造/历史共 60 次操作、20 次取消、1 秒末尾空闲。均开启相同的帧时间探针，无 CLR 跟踪。顺序为前→后→后→前，采样期间不运行构建、诊断或其他基准。

    组别 首次删除帧 ms 处理→绘制前 ms 全部帧 / 长帧 全部窗口最大帧 ms 操作响应最大 ms 原生前台 self / other
    before-a 9.241 8.937 9,806 / 85 37.364 169.575 143 / 0
    after-a 2.109 1.800 9,976 / 81 36.147 164.948 143 / 0
    after-b 1.890 1.586 11,218 / 81 34.609 158.238 144 / 0
    before-b 9.783 9.290 11,174 / 82 37.303 151.597 143 / 0

    四组共 496 项检查、240 次操作通过，原生前台最大轮询间隔均为 82 ms。首次删除帧按真实 SetToolMode:2 调用所在区间定位，没有挑选窗口最低值。逐窗 P95/P99/最大值、全部帧和操作指标位于各 render-25.json，并在 summary.json 汇总；所有窗口 P95 均在 6.9444 ms 内，但明显长帧仍存在。四个短样本只确认这一首次使用问题的改善，未证明总体稳定 144 FPS 或四档最终达标。

    回归与显示¶

    新增 tests/godot/v4_hud_font_runtime_contract.gd：修复前只在“面板字体必须采用普通栅格化”项失败（进程 exit=1），修复后 17 项全部通过（exit=0）。验证全局字体保持 MSDF、字体家族及字号不变、中文实际 shaping 产生有效回退字形、Help/Status/ToolMode 共用局部字体、切换工具不改变地图，以及删除帮助文字仍显示。测试脚本及 UID 在三个导出预设中排除。

    独立真实 Vulkan 截图对照 hud-fixed.png / hud-original.png 已检查：中文完整可读、工具和帮助文字未裁切；字体均为 Open Sans SemiBold/16，默认字体 MSDF 仍为 true。普通字形栅格化带来轻微像素度量差异，帮助区域由 y=759、高 73 px 变为 y=760、高 75 px；没有宣称像素级完全一致。

    Debug build 0 警告/错误；Roslyn 目标文件及 SimpleCities compiler/analyzer diagnostics 为空；导出成功且两份程序集均优化。ExportPresetContractTests|V4RoadOperationTests 聚焦测试 4/4 通过，GDScript 诊断为空。导出日志中的既有 UID、MCP 端口占用、ImGui GDExtension 错误保留；实际独立运行的 stderr 及引擎错误检查通过。构建输入在导出后重新校验，生产代码没有采样后修改。

    编辑器确实启动了正确 V4 场景，DAP stdout 有 bridge initialized/ready，stderr 无新错误。但 exec 与截图请求均超时；按 QA 规则咨询只读诊断后 stop/run 再尝试极小读取仍超时。未更改用户配置、重启编辑器或宣称 editor 输入验证通过。此通信门保持阻塞，独立运行的契约/截图及 Release 真实输入重放不替代它。原游戏已停止，临时槽均清理。

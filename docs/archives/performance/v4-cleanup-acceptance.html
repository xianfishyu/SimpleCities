    V4 旧生产路径清理与最终验收¶

    日期：2026-10-08；基点：5915a018。 GitHub #23 的本地实施与验收记录；远程工单、父规格、标签、评论及推送未修改。 证据目录：.scratch/v4-cleanup-20261008/。

    已完成范围¶

    正式 MapTest 继续使用唯一 V4 路网、历史、表现、工具适配及存档参与者。删除旧 RoadGraph、RoadBuilder、RoadRenderer、RoadSystem、曲线实现、旧道路 reader/writer、旧工具会话及 GridSystem；道路目录只保留 V4 和 HUD 所需的 RoadConfig、RoadType、RoadTypeStyle。配置只承担格长和颜色目录，旧物理宽度及曲线/路口渲染字段退出。

    纯加载表现准备提取为 RoadLoadPresentationPreparer，运行时和应用测试共用。核心仍是独立 SimpleCities.RoadCore.dll，应用不重复编译核心源码；Clipper2 依赖由核心持有。ImGui.NET 和 ImGuiGodot 的 C# 仅 Debug 编译。

    开发导出插件在导出内存设置中移除 ImGui/MCP autoload、编辑器插件目录及 MCP/ImGui 配置，结束后恢复设置和顺序；它不保存这些临时设置到源 project.godot。发布过滤移除 addons、开发探针与测试资源，并过滤全局脚本类缓存。删除 17 个已退役专名过滤，不保留失效的 V3 测试路径。

    保留通用 SaveSlotStore 槽位、锁和事务协议。V3Json、manifest、publication/deletion descriptor 的容器实现不是 V3 道路 reader/writer；manifest 沿用现有 SaveSlotStore 容器协议（指南 §5.8），格式标识仍为 simple-cities-v3，道路载荷使用 schema 6 的 simple-cities-v4，根为 user://saves-v4。不读取、转换或覆盖旧道路存档。

    道路显示比例 0.25、历史 64 笔且不因字节大小拒绝编辑、取消警戒 10 ms worker / 100 ms 工具保持原决定。未修改生产 GC 或加入强制回收。

    编辑器嵌入窗口物理尺寸为 410×231；宿主覆盖物理 resize，因此功能复验仅对临时游戏设置 1600×900 逻辑 viewport，读回 HUD 布局，按实际 stretch transform 换算输入并用逻辑可见矩形检查状态栏。此项证明真实编辑器/DAP功能，独立 1600×900 Vulkan/Release 负责桌面尺寸及性能。临时节点和游戏已停止，用户编辑器及未保存资源保留；自动序列化副本归档后恢复本轮主场景源码，未覆盖无关 UI 工作。

    平台未直接暴露 Godot/Roslyn MCP 绑定，使用本轮标准 MCP 客户端连接实际服务器，Roslyn 仅 session trust；未更改全局 MCP 配置。server 4.1.11 / addon 4.1.0 版本差异保留披露。

    源码和产物身份¶

    原编辑器持有原生 DLL，直接同目录 headless export 曾报共享锁错误。最终导出使用独立物理副本，不强杀或丢弃编辑器未保存内容。采样副本 553 文件、最后导出副本 554 文件（新增身份核对 helper）有双副本 hash；唯一 project.godot 设置差异是副本关闭编辑器 MCP 插件以避免端口争用，发布包均由导出边界移除开发设置。

    正式矩阵已经逐项核对 278 个实际构建/运行输入及原始源码身份，前后副本 hash 未改变，实际二进制重新核验通过。原执行 runner 也按其记录 hash 归档。新 runner 在导出前和测量后核对实际 ExportProjectPath，summarizer 强制核对源/副本绑定；缺折线建造窗口、缺建造操作、陈旧副本三项否定验证全部拒绝。

    更新后的完整 runner 另做 25 米短流程集成验证，71 项通过，导出前和测量后 278 输入身份均通过。首次短流程准确拒绝编辑器自动把 RoadConfig 的 100 重写成 100.0 所造成的源/副本 hash 不一致；自动序列化副本已归档，恢复规范源码后重跑通过。短流程只验证脚本接入，不替代上述五组持续数据。

    审查后只改变过滤中的已删除路径、开发插件变量名、QA 脚本/身份检查；采样与最终包的 C#、工程引用及运行资源源码一致。不同物理构建路径产生不同完整程序集 hash，两份身份分别留存；对应用 2404、核心 1149 个方法的签名、属性和 IL 比较完全一致，未冒称完整二进制 hash 相同。见 final-measured-method-binding.json、源副本 manifest 和各包扫描。

    失败历史与收口范围¶

    保留缺恢复导致的 Debug ImGui 资产错误、旧 DLL 缺探针、原目录 DLL 共享锁、未建 Debug 的导出源编辑器错误、首次 QA Node API 解析错误、首次只读错误分类、嵌入视口越界、临时 runner 编码/重置前提错误、外部调试器无法连接及错误 bootstrap 入口。外部窗口尝试没有作为编辑器/DAP证明；最终回到真实原生播放会话完成全部断言。编辑器日志最初四条旧 scratch 缓存/模态错误为基线，未隐藏或算作本轮零错误。

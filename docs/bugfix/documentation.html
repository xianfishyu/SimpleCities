    文档系统 Bug 修复记录¶

    日期：2026-10-26 影响文件：docs/bugfix/、docs/todo/ 的追溯引用，以及现行规格、存档说明、ADR 和归档入口 关联事项：documentation:3.1 的语义完整性复审

    BUG-1：报告迁移后纯文本追溯路径失效¶

    症状¶

    从修复记录或系统待办中的“完整报告见”等说明复制旧路径，找不到已迁移的文档；例如道路表现 BUG-14 指向的报告现位于历史报告目录。原 Markdown 链接检查仍通过。

    根因分析¶

    迁移只调整了 Markdown 链接的目标；反引号中的纯文本路径不在链接检查器范围内。路径文字虽然保留了历史身份，却缺少当前可用的跳转。

    修复方案¶

    为修复记录和系统待办的 40 处旧文档路径补上相对链接，保留原路径作为链接文字；在文档维护规则中要求追溯路径使用 Markdown 链接。已带正确目标的历史路径标签不重复嵌套。

    影响范围¶

    涉及 13 份修复记录或待办文档的导航。原文字、数值、日期、任务状态及延期条件保留，运行证据路径和清单不改写。

    BUG-2：仍有效的载荷规范仅在历史原稿中具体定义¶

    症状¶

    V4 指南整体归档后，现行规格只概述“确定的起点与方向”，存档说明要求拒绝非法自环 seam，但具体合法性规则仍只在历史原稿中。读者无法从现行契约确定合法方向。

    根因分析¶

    重构保留了规则文字，却没有同步恢复现行规范的权威入口；归档头部、存档说明与 ADR 的跳转也没有区分当前要求和原讨论。

    修复方案¶

    将结构节点合并、开放边定向、纯环 rooted seam、自环字典序方向及 reader/确定性要求提取到现行规格。存档、道路系统与 ADR 直接引用该处，归档抬头注明现行去向；不重复复制整份指南。

    影响范围¶

    只恢复文档的规范表达与追溯入口。按现有 RoadMutationDraft、RoadTopology、RoadCodec 和测试源码静态核对，未改变实现、schema 或已接受的领域取舍，历史原稿正文保留。

    验证状态¶

    • BUG-1：40 处迁移路径均有存在的目标；相关范围内没有遗留的未链接迁移路径。去除新增链接包装后，13 份文档的原文字保持一致。
    • BUG-2：5 项现行规则与当前源码约束静态对照；存档、道路系统、ADR 与归档入口均可直达现行规范。
    • 两项修复：156 个既有任务复选框、62 条用户故事、25 条实施决定、12 条测试决定、9 条排除范围保持一致；12 份原证据配套文件的原始 SHA-256 与重构前快照相同。
    • python Scripts/Docs/check_docs.py 与 git diff --check：通过。验证仅覆盖文档与静态约束，本次未重跑 Godot 或性能验收。
    • BUG-3（2026-11-03）：通过发布工具的 -SkipBuild -CheckConnection 读取远程 HEAD；检查模式未执行发布或 Pages 配置写入。该验证覆盖代理继承与 Git 连通性，正式部署另外验收。

    BUG-3：Pages 发布命令未继承 Windows 系统代理¶

    日期：2026-11-03 影响文件：publish_docs.ps1

    症状¶

    静态文档站和 HTML 链接检查均已通过，GitHub API 也可以访问；执行发布时，Git HTTPS 连接 GitHub 的 443 端口超时，发布分支没有上传。

    根因分析¶

    发布工具只为 Git 配置了 GitHub 凭据助手，没有传递 Windows 已配置的代理。该环境中 Python/系统网络请求能读取系统代理，而 Git 的直接连接无法到达 GitHub；凭据有效并不能修复这条网络路径。

    修复方案¶

    通过文档站独立 Python 环境的 urllib.request.getproxies() 读取当前环境或 Windows 系统 HTTP/HTTPS 代理，为发布工具的每次 Git 调用传入临时 -c http.proxy=...。不写入全局 Git 配置或系统设置。

    增加 -CheckConnection 模式，只执行目标仓库的 ls-remote ... HEAD 后返回；它便于在上传前独立验证同一套代理和凭据参数。

    影响范围¶

    影响静态文档站发布及其连接诊断入口；沿用专门的发布工作区和发布分支，不改变源码分支、Godot 运行代码或存档协议。

    验证¶

    ./Scripts/Docs/publish_docs.ps1 -SkipBuild -CheckConnection 成功返回远程 HEAD，原先的 Git 连接超时未再出现。代理参数由实际系统配置读取，不将本机端口硬编码为所有环境的默认值。

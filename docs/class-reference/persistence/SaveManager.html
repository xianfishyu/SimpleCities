    SaveManager¶

    类参考首页 · 持久化与联合加载 · 类型索引

    继承 / 实现： Node

    协调活动场景保存策略、参与者、异步存储操作和场景退出的 Autoload。

    种类： class　声明可见性： public　命名空间： 全局

    描述¶

    协调活动场景保存策略、参与者、异步存储操作和场景退出的 Autoload。Start 系列返回操作 token，由结果接口观察完成。

    StartSave、StartSaveAs、StartAutosave 和 StartLoad 返回操作 token。调用方需要继续等待 HasOperationResult，再读取结果；返回 token 不代表操作已经成功。

    结果的 resultKind、committed、warnings 与 error 必须分别判读。决定性提交后的观察或清理问题不能被当作“从未提交”，盲目重发可能重复执行操作。

    删除先生成与槽占用摘要绑定的确认 token，再用匹配的 token 启动。场景退出通过协调器停止准入并等待已有操作收敛。

    注意： tests/godot/ 中的声明由主项目 Debug 配置纳入。它们补充测试和故障注入接口，表中保留相应标记。

    SaveOperationCoordinator¶

    类参考首页 · 持久化与联合加载 · 类型索引

    继承 / 实现： IAsyncDisposable

    序列化存储操作：手动操作等待准入，自动保存合并待执行请求，并处理取消与关闭收敛。

    种类： class　声明可见性： internal　命名空间： 全局

    描述¶

    序列化存储操作：手动操作等待准入，自动保存合并待执行请求，并处理取消与关闭收敛。

    手动操作异步等待准入；自动保存忙时合并待执行请求。关闭期间停止接受新操作并请求适用取消，直到当前租约释放后才完成收敛。

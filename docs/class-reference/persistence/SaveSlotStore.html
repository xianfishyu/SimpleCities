    SaveSlotStore¶

    类参考首页 · 持久化与联合加载 · 类型索引

    基础类型： System.Object

    同根目录文件事务实现：分类槽占用、锁定保存根、预备/发布/恢复保存和删除，并验证字节摘要与路径边界。

    种类： class　声明可见性： internal　命名空间： 全局

    描述¶

    同根目录文件事务实现：分类槽占用、锁定保存根、预备/发布/恢复保存和删除，并验证字节摘要与路径边界。

    该类处理同一保存根中的文件事务、根锁、占用分类和恢复。正式 UI 使用 SaveManager 的协调入口；独立底层同步入口不提供完整场景联合加载语义。

    枚举¶

    名称 说明
    PathDigestKind 描述单一路径摘要的可用状态，用于保守处理不存在、有效与不安全的路径。
    OccupantDigestKind 描述槽占用摘要计算的分类结果，供覆盖、删除确认和恢复判断使用。

    嵌套类型¶

    名称 说明
    SaveParticipant 保存事务中验证后的文件参与者及其快照。
    SaveParticipantDefinition 已验证的载荷文件名及其保存参与者。
    SlotEntrySnapshot 捕获槽内目录和文件名称，用于检测事务过程中目录内容是否改变。
    PathDigestState 带种类和摘要的路径观测结果。
    OccupantDigestState 带种类和摘要的槽占用观测结果。

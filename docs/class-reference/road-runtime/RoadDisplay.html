    RoadDisplay¶

    类参考首页 · 道路 Godot 运行适配 · 类型索引

    继承 / 实现： IDisposable

    一个不可变 Godot 道路表现版本，统一持有绘制页、命中索引和来源快照，支持局部重建与资源复用，最终由 Dispose 释放。

    种类： class　声明可见性： internal　命名空间： 全局

    描述¶

    一个不可变 Godot 道路表现版本，统一持有绘制页、命中索引和来源快照，支持局部重建与资源复用，最终由 Dispose 释放。

    几何与空间索引准备可在 worker 进行；ArrayMesh 等 Godot 资源的创建和上传留在主线程预检阶段。绘制与命中共享转换后的表面片。

    多个显示版本可共享未变化的网格页。Dispose 结束本对象持有期，仅在最后持有者释放时清理共享资源。

    嵌套类型¶

    名称 说明
    PageKey 由表面层和首个所有者身份确定的网格分页键。
    Piece 转换到 Godot 坐标的绘图片，保存多边形、中心线来源和所属几何组。
    PaintComparer 为转换后的绘图片提供与表面层次一致的稳定绘制顺序。
    GeometryGroup 可复用的 Godot 几何组，保留核心表面组与转换后的片段。
    GeometryPage 按 PageKey 聚合的几何组页面。
    MeshArrays 准备上传的顶点、颜色和三角索引数组，不是已经上传的 ArrayMesh。
    PageMeshes 一页几何与其已上传网格的资源所有权记录，支持共享和释放。
    ResourceSet 当前表现持有的分页网格资源集合，集中处理资源引用及释放。
    PreparedGeometry 后台几何准备结果及上传诊断量，Upload 在引擎资源预检阶段生成可发布 RoadDisplay。
    Fragment 用于表面命中粗筛的绘图片片段及包围盒。
    PieceIndex 不可变表面空间索引，保留稳定片段身份，局部更新只替换受影响的桶。
    HitResult 表面命中对应的核心道路位置及可选路口节点归属。

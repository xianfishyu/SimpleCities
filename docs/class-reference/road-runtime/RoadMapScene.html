    RoadMapScene¶

    类参考首页 · 道路 Godot 运行适配 · 类型索引

    继承 / 实现： Node2D、ISceneToolLoadParticipant

    正式道路场景装配根，唯一持有路网、工具会话、操作仲裁、表现流程和场景存储准入；HUD 与探针从此驱动同一套状态。

    种类： class　声明可见性： public　命名空间： 全局

    描述¶

    正式道路场景装配根，唯一持有路网、工具会话、操作仲裁、表现流程和场景存储准入；HUD 与探针从此驱动同一套状态。

    场景唯一持有权威 RoadNetwork，工具、历史、加载准入与表现操作都经过同一个装配根。HUD 消费 presented 版本的统计，避免混读新核心与旧画面。

    一次写操作经过私有规划、纯表现准备、主线程资源预检、引用提交、表现发布和首次正确绘制。提交后的显示重试只重建表现，不重复追加道路编辑或历史。

    注意： tests/godot/ 中的声明由主项目 Debug 配置纳入。它们补充测试和故障注入接口，表中保留相应标记。

    枚举¶

    名称 说明
    DisplayPhase 表现状态机的内部阶段，用于区分当前、失败、准备与等待首次绘制。

    嵌套类型¶

    名称 说明
    CompletedPreview 缓存某次建造请求及其规划预览结果和状态文字。
    PlannedRoadOperation 后台道路写操作规划结果，区分有计划、无变化和拒绝原因。
    ToolAdmission 加载期间的工具准入和重置提交计划，按场景世代防止旧交互进入新状态。

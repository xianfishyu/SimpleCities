    RoadMapView¶

    类参考首页 · 道路 Godot 运行适配 · 类型索引

    继承 / 实现： Node2D、IScenePresentationLoadParticipant

    Node2D 表现装配与联合加载参与者，持有 presented 快照、当前/可复用显示、草稿预览和格段高亮。

    种类： class　声明可见性： public　命名空间： 全局

    描述¶

    Node2D 表现装配与联合加载参与者，持有 presented 快照、当前/可复用显示、草稿预览和格段高亮。

    Presented 表示视图当前持有的完整表现快照。画面、命中、高亮和 HUD 统计须使用同一来源，不能只替换其中一部分。

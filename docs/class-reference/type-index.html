    类型总索引¶

    类参考首页 · 类型总索引

    按完整类型名查找。生产、内部和测试类型均保留，类型正文各自独立成页。

    类型 种类 声明可见性 用途
    AutosaveController class public 场景内的自动存档调度节点，默认周期 300 秒，Timer 随场景暂停。
    AutosaveController.AutosaveCompletedEventHandler delegate public 自动存档完成信号的委托声明，向观察者提供成功标记。
    CandidateHolder class internal 性能测量中人为保留候选对象的持有器，用于控制存活期。
    CapturedLoadParticipant record internal 把载荷名、加载目标及提前捕获的读取器绑定，使后台解析不重新访问场景。
    CapturedSaveParticipant record internal 把载荷文件名、保存参与者和已捕获快照绑定，供后台写盘使用。
    ConstructionCategoryDefinition class public 建造分类 Resource，包含稳定分类 ID、显示文字、排序和工具资源列表；校验重复工具类型及排序。
    ConstructionDock class public 常驻底部建造栏，按资源生成工具按钮，与 RoadToolManager 同步选择并维护焦点链和指针占用范围。
    ConstructionDock.BuiltInToolPresentation record private 内置工具的名称、说明和快捷键提示回退数据。
    ConstructionDock.CategoryDescriptor record private 内置建造分类按钮的身份、文字和视觉元数据。
    ConstructionDock.PlaceholderDescriptor record private 尚不可用分类的显示与占位说明数据。
    ConstructionDockButton class public 建造坞复用的按钮组件，集中显示图标、文字、选中状态及自定义视觉。
    ConstructionDockButton.PresentationColors record struct private 按钮绘制所需的一组颜色值，按视觉角色和交互状态选择。
    ConstructionDockButtonVisualRole enum public 区分一级分类按钮和二级工具按钮，决定选中指示器的呈现方式。
    ConstructionToolDefinition class public 单个建造工具 Resource，由建造坞与上下文面板共享；包含稳定 ID、工具类型、名称、图标、排序和说明。
    DebugPanel class public 显示 FPS、鼠标网格位置与当前 presented 路网统计的轻量诊断面板，支持焦点导航和收起。
    GameHUD class public 游戏 HUD 组合根，解析道路和输入依赖、连接子面板、消费产品输入、协调暂停与响应式布局。
    HistoryHolder class internal 性能测量中人为保留历史对象的持有器，用于区分共享与释放行为。
    INonThrowingLoadCommitPlan interface internal 联合加载的预检产物契约，分离世代检查、引用交换、通知和提交后清理。
    InputBindingManager class public Autoload 输入绑定服务，维护十一项可配置动作，更新 InputMap 并保存到 user://input_bindings.cfg。
    InputBindingManager.BindingDefinition record public 一项可绑定动作的稳定名称、显示名、分组、默认键与可选工具映射。
    IPreparedSaveState interface public 已经完整解析和验证、可供提交的加载状态标记。
    IPreparedScenePresentation interface internal 可跨准备线程传递的纯表现数据标记，不代表引擎资源已经上传。
    ISaveFileParticipant interface public 给持久化参与者分配稳定载荷文件名，是保存和加载两个方向的共同身份契约。
    ISaveSnapshot interface public 保存参与者在捕获阶段交出的不可变状态标记，供后台编码读取。
    ISceneNetworkLoadAdmission interface internal 锁定网络的加载准入，预检准备状态并产生网络引用提交计划及目标状态。
    ISceneNetworkLoadParticipant interface internal 网络存储参与者与场景加载准入的组合契约。
    IScenePresentationLoadAdmission interface internal 表现准入租约，提供后台准备器并预检目标表现的提交计划。
    IScenePresentationLoadParticipant interface internal 按场景世代绑定表现参与者并提供加载准入。
    IScenePresentationPreparer interface internal 把验证后的网络状态转成纯表现数据的后台准备契约。
    ISceneToolLoadAdmission interface internal 工具准入租约，预检完整交互重置并生成提交计划。
    ISceneToolLoadParticipant interface internal 提供工具状态的联合加载准入，确保加载不会保留旧草稿或选择。
    IStorageOperationLease interface internal 底层存储操作的取消与提交边界契约，供流包装器、槽事务及联合加载共享。
    IStreamingLoadReader interface public 从字节流解析并验证加载内容，返回准备状态，不直接发布活动会话。
    IStreamingLoadTarget interface public 提供被捕获的加载读取器，以及对准备状态的提交入口。
    IStreamingSaveable interface public 组合流式保存和流式加载目标契约，供通用槽容器注册参与者。
    IStreamingSaveParticipant interface public 定义快照捕获与向字节流编码；捕获与编码分开，使主线程状态无需在写盘阶段继续被访问。
    LoadPreflightInvalidException class internal 加载预检产物在正式提交前因场景或参与者世代变化而失效时使用的异常。
    MainCamera class public Camera2D 输入与平滑控制：当前绑定的键盘平移、中键拖动、围绕指针的滚轮缩放。
    MainMenu class public 城市场景结束后的最小入口页，进入 CityMap 或通过保存协调器申请退出。
    MapBackground class public CanvasLayer 地图背景，通过 ShaderMaterial 显示主网格、次网格和点阵。
    PauseMenu class public 全屏模态暂停菜单，管理视图、焦点、按键重绑定、存储操作、确认和退出等待；游戏流程通过事件交给 GameHUD。
    PauseMenu.ConfirmationAction enum private 确认对话框即将执行的动作类别。
    PauseMenu.MenuOperationAction enum private 当前异步槽操作的菜单动作类别。
    PauseMenu.MenuView enum private 暂停菜单当前显示的子视图。
    PreparedAggregateLoad class internal 汇集网络、工具、表现和槽身份等加载计划，在同一提交边界同步交换引用，再逐一发布通知与清理。
    PreparedRoadPresentation record internal 道路目标快照与 PreparedGeometry 的加载组合，作为通用准备表现标记传递。
    PreparedSaveParticipant record internal 把一个加载目标与它已经准备好的状态绑定。
    PreparedSaveSlot class internal 一个槽内全部加载参与者的准备结果，可按目标取回状态；正式场景使用联合加载路径。
    PreparedSceneLoad class internal 完整槽准备结果及其纯表现准备结果，尚未向活动场景发布。
    RoadConfig class public Godot Resource，提供 HUD 道路样式目录和背景显示格长。
    RoadDisplay class internal 一个不可变 Godot 道路表现版本，统一持有绘制页、命中索引和来源快照，支持局部重建与资源复用，最终由 Dispose 释放。
    RoadDisplay.Fragment class private 用于表面命中粗筛的绘图片片段及包围盒。
    RoadDisplay.GeometryGroup class private 可复用的 Godot 几何组，保留核心表面组与转换后的片段。
    RoadDisplay.GeometryPage record private 按 PageKey 聚合的几何组页面。
    RoadDisplay.HitResult record struct internal 表面命中对应的核心道路位置及可选路口节点归属。
    RoadDisplay.MeshArrays record internal 准备上传的顶点、颜色和三角索引数组，不是已经上传的 ArrayMesh。
    RoadDisplay.PageKey record struct internal 由表面层和首个所有者身份确定的网格分页键。
    RoadDisplay.PageMeshes class private 一页几何与其已上传网格的资源所有权记录，支持共享和释放。
    RoadDisplay.PaintComparer class private 为转换后的绘图片提供与表面层次一致的稳定绘制顺序。
    RoadDisplay.Piece class private 转换到 Godot 坐标的绘图片，保存多边形、中心线来源和所属几何组。
    RoadDisplay.PieceIndex class private 不可变表面空间索引，保留稳定片段身份，局部更新只替换受影响的桶。
    RoadDisplay.PieceIndex.Query class private 一次表面查询的局部预算、候选与精确命中累计器。
    RoadDisplay.PreparedGeometry class internal 后台几何准备结果及上传诊断量，Upload 在引擎资源预检阶段生成可发布 RoadDisplay。
    RoadDisplay.ResourceSet class private 当前表现持有的分页网格资源集合，集中处理资源引用及释放。
    RoadDisplayFailureProbe class public Godot Debug 运行探针，用于观察或注入显示发布和绘制失败及重试。
    RoadDisplayPreflightProbe class public Godot Debug 运行探针，用于观察或注入表现预检、网格上传与失败保护。
    RoadFrameAllocationProbe class public Godot Debug 运行探针，用于观察或注入分阶段帧耗时与托管分配采样。
    RoadFrameAllocationProbe.Sample record struct private RoadFrameAllocationProbe 内部的测试/测量辅助类型。
    RoadFrameAllocationProbe.Window record private RoadFrameAllocationProbe 内部的测试/测量辅助类型。
    RoadHistoryReuseProbe class public Godot Debug 运行探针，用于观察或注入撤销/重做的显示资源复用。
    RoadIncrementalDisplayProbe class public Godot Debug 运行探针，用于观察或注入增量显示与完整重建的一致性。
    RoadLoadPresentationPreparer class internal 在加载 worker 中构造纯道路表现准备结果，引擎网格上传仍留在主线程预检。
    RoadLoadWorkProbe class public Godot Debug 运行探针，用于观察或注入加载各阶段工作量与线程行为。
    RoadLoadWorkProbe.Observer class private RoadLoadWorkProbe 内部的测试/测量辅助类型。
    RoadMapScene class public 正式道路场景装配根，唯一持有路网、工具会话、操作仲裁、表现流程和场景存储准入；HUD 与探针从此驱动同一套状态。
    RoadMapScene.CompletedPreview record private 缓存某次建造请求及其规划预览结果和状态文字。
    RoadMapScene.DisplayPhase enum private 表现状态机的内部阶段，用于区分当前、失败、准备与等待首次绘制。
    RoadMapScene.PlannedRoadOperation record private 后台道路写操作规划结果，区分有计划、无变化和拒绝原因。
    RoadMapScene.ToolAdmission class private 加载期间的工具准入和重置提交计划，按场景世代防止旧交互进入新状态。
    RoadMapView class public Node2D 表现装配与联合加载参与者，持有 presented 快照、当前/可复用显示、草稿预览和格段高亮。
    RoadMapView.Admission class private 表现加载准入，捕获世代并提供纯表现准备器。
    RoadMapView.CommitPlan class private 预检通过的表现引用交换计划，提交后再通知与释放旧显示。
    RoadMapView.PreviewSegment record private 一个预览绘制段及其颜色、冲突标记和示意宽度。
    RoadOperation class public 单笔道路写入的主线程仲裁状态机：准备、取消、提交与首次绘制计时。
    RoadOperationTests class public 验证道路操作的忙状态、取消、提交和首次绘制的测试集合。
    RoadOperationWorkProbe class public Godot Debug 运行探针，用于观察或注入道路操作准备阶段的阻塞、取消和工作量。
    RoadSaveParticipant class internal 将纯核心快照和 codec 接到通用槽事务及联合加载协议，不让纯核心依赖 Godot 或应用持久化接口。
    RoadSaveParticipant.Admission class private 网络加载准入，检查计划可提交并产生网络引用提交计划。
    RoadSaveParticipant.CommitPlan class private 经预检的网络引用交换计划，正式边界内提交网络，后续阶段再清理准入。
    RoadSaveParticipant.Prepared record internal 网络读取器完整准备的载荷及对应加载计划。

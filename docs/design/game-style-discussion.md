# 游戏风格探讨：我们需要怎样的城市建造游戏？

> 状态：已确认核心定位 | 最后更新：2026-05-23

---

## 0. 最新确认决策

| # | 问题 | 决策 |
|---|------|------|
| 1 | 三种玩法（主动/挂机/创作） | **三者共存**，不排斥任何一种 |
| 2 | 破产会结束游戏吗 | **会破产，不结束**（软失败，类似天际线） |
| 3 | 离线城市会崩溃吗 | **城市自调节**，不会轻易崩溃 |

## 1. 重新定义：这是"城市规划模拟"而非"城市建造"

由于不渲染个体建筑，这个游戏的本质与 SimCity / Cities: Skylines 产生了根本差异：

| | SimCity / 天际线 | SimpleCities |
|---|---|---|
| 视觉核心 | 建筑 3D/2D 模型 | 彩色分区多边形 |
| 基本操作 | 划定分区 → 看建筑长出来 | 划定分区 → 分区本身就是结果 |
| 玩家关注点 | "这个建筑好不好看" | "这片区域的功能是否合理" |
| 类比 | 乐高城市 | 城市规划局长的桌面地图 |

> **定位**：这是一个"城市规划桌面沙盘"。像一位规划局长在纸质地图上用彩色马克笔划分功能区，然后观察城市数据随时间演变。

## 2. 三种玩法如何在"规划地图"中实现

### 路径 A：主动管理（规划局长）

```
打开游戏 → 查看数据面板（人口→, 财政↘, 交通↗拥堵）
→ 分析交通热力图 → 新建一条主干道分流
→ RCI 显示商业需求高 → 在交通便利处画一片 C 区
→ 调低商业税率刺激增长 → ×1000 加速观察效果
→ 满意，关闭
```

### 路径 B：观察挂机（城市观察者）

```
3 天没上线 → 打开游戏
→ 离线报告：「人口 +1200, 自动新建 2 个 R 区, 财政盈余 ¥5000」
→ 扫一眼规划图：城市向东北自然扩展了
→ 微调一处拥堵路段 → 什么都不做，看城市自己运转
→ 关闭
```

### 路径 C：美学创作（地图画家）

```
打开游戏 → 不关心模拟数字
→ 花 1 小时精细绘制道路网络（几何对称、环线+放射线）
→ 用不同色块填充分区，追求配色和谐
→ 加入公园、水系，创造"花园城市"视觉效果
→ 截图 → 设为桌面壁纸
```

## 3. 视觉定位：城市规划图的极简美学

既然只有分区色块 + 道路线条，视觉上天然就是一张"地图"。关键设计决策：

### 3.1 调色板

```
R 住宅：   ██ 暖绿  #4CAF50
C 商业：   ██ 蓝灰  #607D8B
I 工业：   ██ 暖黄  #FFC107
O 办公：   ██ 淡紫  #9C27B0
M 混合：   ██ 橙色  #FF9800
G 绿地：   ██ 浅绿  #8BC34A
水域：     ██ 浅蓝  #81D4FA
道路：     ── 深灰  #37474F
```

### 3.2 视觉层次

| 层级 | 元素 | 透明度 |
|------|------|--------|
| 底 | 地形（水域、不可建造区） | 100% |
| 中 | 分区色块 | 40~60% |
| 中上 | 道路线条 | 100% |
| 顶 | 选中高亮/数据叠加层 | 可变 |

---

## 4. 总结：我们正在构建什么

**一个城市规划桌面沙盘。**

- 玩家像规划局长，在矢量地图上划分功能区
- 城市按真实时间缓慢演进，玩家可随时干预或放任
- 视觉极简如 Mini Metro，模拟深度对标天际线
- 破产不终结，城市有自愈力
- 为超大地图和多人世界预留空间

# 核心模拟系统大纲

> 状态：草案 | 最后更新：2026-05-23

---

## 0. 核心设计原则：分区即原子单元

**不渲染个体建筑。** 玩家只看到分区色块 + 道路网络。

所有模拟数据——人口、就业、税收、污染——聚合在**分区多边形**内。一个分区就是一个"数据容器"，如同现实中的城市规划地图。

```
分区 = {
    几何:      多边形顶点列表,
    类型:      R | C | I | O,
    密度等级:  低 | 中 | 高,
    聚合数据:  { 人口, 岗位数, 土地价值, 污染, 税收产出, ... }
}
```

这种抽象的优势：
- 视觉极简 — 画面就是一张彩色规划图
- 性能优越 — 无需管理成千上万个建筑实体
- 数学友好 — 分区间交互可用空间经济学模型描述
- 规划导向 — 玩家思考"这片区域的功能"，而非"这个建筑放哪里"

## 2. 时间系统

### 2.1 时间尺度

| 概念 | 实现 |
|------|------|
| 基础时钟 | **1:1 对应现实时间**（真实每秒 = 游戏内每秒） |
| 速度控制 | 暂停 / 1×（实时） / ×10 / ×100 / ×1000 / ×10000 |
| 日历 | 年-月-日-时-分-秒，与现实公历一致 |
| 昼夜循环 | 视觉调色（非必需，极简风格可省略） |
| 季节 | 春/夏/秋/冬，影响能耗、农业（若引入） |

> **设计意图**：1:1 基础时钟赋予城市生长"真实感"。玩家离线期间城市持续运行，
> 上线后查看发展结果并进行干预。加速倍率用于跳过等待期。

### 2.2 时间驱动事件

每游戏日触发：
- 税收结算
- 市民通勤（上班/回家）
- 商业营业
- 人口统计更新
- 服务设施运行

## 3. 分区系统 — 核心原子单元

### 3.1 分区绘制

| 方式 | 操作 | 适用场景 |
|------|------|----------|
| **自由绘制** | 鼠标拖拽出任意多边形 | 精细规划，异形地块 |
| **一键填充** | 点击道路闭合区域自动填充 | 快速开发规整街区 |

### 3.2 分区类型

| 分区 | 缩写 | 颜色 | 说明 |
|------|------|------|------|
| 住宅区 | R | 🟢 绿 | 市民居住，产生通勤需求 |
| 商业区 | C | 🔵 蓝 | 商品销售、就业岗位 |
| 工业区 | I | 🟡 黄 | 产品生产、就业岗位，产生污染 |
| 办公区 | O | 🟣 紫 | 白领就业，低污染 |
| 混合区 | M | 🟠 橙 | 住宅+商业混合（后期解锁） |
| 绿地/公园 | G | 🌿 浅绿 | 提升幸福度与地价，无建筑数据 |

### 3.3 分区聚合数据

每个分区多边形承载以下指标（所有建筑相关数据聚合于此）：

| 属性 | 说明 | 计算来源 |
|------|------|----------|
| 面积 | 多边形面积 | 几何计算 |
| 密度等级 | 低/中/高 | 玩家设定或自动升级 |
| 人口容量 | 最大可容纳市民数 | 面积 × 密度系数 × 分区类型系数 |
| 当前人口 | 实际居住/工作人口 | 模拟引擎动态更新 |
| 就业岗位 | 提供的工作数量 | 面积 × 岗位密度系数 |
| 土地价值 | 地价指数 (0~1) | 交通可达性 + 服务覆盖 + 环境 + 邻区效应 |
| 税收产出 | 每周期税收 | 人口/岗位 × 税率 × 土地价值修正 |
| 污染产出 | 污染排放量 | 分区类型系数（I 区高、O 区低、R/C 中） |
| 幸福度 | 居民/企业满意度 (0~100) | 服务覆盖 + 环境 + 通勤便利性 + 税率 |

### 3.4 RCI 需求系统

```
需求条 = { R需求, C需求, I需求, O需求 }

需求变化 = f(
    当前人口,      // 人口越多，商业需求越高
    空置率,        // 住房空置率高 → 住宅需求下降
    就业率,        // 就业率高 → 吸引更多移民
    税率,          // 税率高 → 需求抑制
    外部需求       // 外部世界对本地产业的需求
)

高R需求 → 住宅区人口增长 → 需要更多R分区面积
高C需求 → 商业区岗位增长 → 需要更多C分区面积
高I需求 → 工业区岗位增长 → 需要更多I分区面积
```

## 4. 人口模拟（统计层面）

### 4.1 人口统计指标

| 指标 | 说明 |
|------|------|
| 总人口 | 城市居民总数 |
| 年龄结构 | 儿童 / 青年 / 中年 / 老年 占比（影响劳动力供给） |
| 教育水平 | 未受教育 / 高中 / 大学 / 研究生 占比（影响 O 区岗位匹配） |
| 就业率 | 有工作人口 / 劳动人口 |
| 财富等级 | 低收入 / 中收入 / 高收入 占比（影响税收和商业需求） |
| 幸福度 | 0~100 综合满意度 |

### 4.2 人口变化方程

```
Δ人口 = 迁入 - 迁出 + 出生 - 死亡

迁入 = k_in  × 就业机会 × 住房空置率 × (1 - 税率惩罚)
迁出 = k_out × (失业率 + 高税收惩罚 + 低幸福度惩罚 + 污染惩罚)
出生 = k_birth × 育龄人口比例 × 幸福度修正
死亡 = k_death × 老年人口比例
```

## 5. 经济系统

### 5.1 城市财政

```
月度预算 = 税收收入 - 运营支出

收入：
  · 住宅税（按R区人口 × 人均税率）
  · 商业税（按C区营业额 × 税率）
  · 工业税（按I区产值 × 税率）
  · 办公税（按O区利润 × 税率）
  · 公共服务收费（水电费）

支出：
  · 道路维护费（按道路总长度 × 道路等级系数）
  · 服务设施运营（警消医教等）
  · 公用事业运营（电力、供水、污水）
  · 贷款利息（如有）
```

### 5.2 破产机制

- 余额 < 0 且持续亏损 → 进入破产状态
- 破产后：所有服务设施效率减半，市民幸福度下降，人口加速迁出
- **不结束游戏**：玩家始终可以通过调整税率、削减支出、等待外部援助来挽救
- 城市具有自调节能力：人口减少 → 支出减少 → 逐步恢复平衡

### 5.3 税率

每种分区独立税率，可调范围 1%~29%。税率影响：
- 高税率 → 收入↑ 但 人口/企业迁出↑
- 低税率 → 吸引力↑ 但 收入↓

## 6. 交通系统

### 6.1 道路层级

| 层级 | 类型 | 限速 | 容量 | 维护费(/格) |
|------|------|------|------|-------------|
| 1 | 土路 | 低 | 低 | 极低 |
| 2 | 普通街道 | 中 | 中 | 低 |
| 3 | 主干道 | 高 | 高 | 中 |
| 4 | 高速公路 | 最高 | 最高 | 高 |

### 6.2 交通模拟（OD 矩阵 + 路径分配）

**不模拟个体出行者。** 使用 Origin-Destination（OD）矩阵描述分区间流量，再分配到道路网络。

- **OD 矩阵**：分区 A → 分区 B 的车流/人流量，由引力模型给出（见 `math-model.md`）
- **路径分配**：每个 OD 对的最短路径（A*），流量叠加到经过的路段
- **拥堵**：路段流量 > 容量 → 通行时间↑ → 影响后续路径选择（用户均衡迭代）
- **显示**：道路以颜色/粗细表示流量饱和度（绿→黄→红）
- **公共交通**（后期）：公交线路在 OD 矩阵中增加公共交通方式分流

### 6.3 出行需求矩阵（引力模型）

分区 A → 分区 B 的出行量 = f(A人口, B岗位数, 距离衰减)

```
流量(A→B) = k × (A.R人口 × B.C岗位) / distance²  // 住宅→商业
流量(A→B) = k × (A.R人口 × B.I岗位) / distance²  // 住宅→工业
流量(A→B) = k × (A.R人口 × B.O岗位) / distance²  // 住宅→办公
```

> 这本质上是**引力模型（Gravity Model）**，详见 `math-model.md`。

## 7. 公用事业

### 7.1 电力

- 发电设施：燃煤/燃气/核电/可再生能源
- 电力沿道路网络传播
- 缺电 → 分区人口/岗位增长率下降

### 7.2 供水与排污

- 水源：河流取水口、地下水井
- 供水沿道路网络传播
- 缺水/水污染 → 市民健康↓ 幸福度↓

## 8. 城市服务

| 设施 | 功能 | 覆盖半径 | 运营成本 |
|------|------|----------|----------|
| 🚔 警察局 | 降低犯罪率 | 中 | 中 |
| 🚒 消防站 | 降低火灾风险 | 中 | 中 |
| 🏥 医院 | 提升健康 | 大 | 高 |
| 🏫 学校 | 提升教育水平 | 中 | 中 |
| 🎓 大学 | 提升高等教育 | 大 | 高 |
| 🌳 公园 | 提升幸福度+地价 | 小 | 低 |
| 🗑️ 垃圾处理 | 降低污染 | 大 | 中 |
| 🏛️ 地标 | 提升地价+旅游吸引力，视觉图标 | 超大 | 高 |

**覆盖计算**：沿道路距离（非欧几里得距离），衰减公式：

```
覆盖效果 = max(0, 1 - 道路距离 / 最大覆盖半径)
```

## 9. 环境系统

| 指标 | 来源 | 影响 |
|------|------|------|
| 空气污染 | I 区、高流量道路 | 健康↓ 地价↓ 幸福度↓ |
| 水污染 | I 区、未处理污水 | 健康↓ |
| 噪声污染 | 主干道、C区、I区 | 幸福度↓ 地价↓ |
| 绿地覆盖 | 公园、森林分区 | 幸福度↑ 污染吸收↑ 地价↑ |

## 10. 外部世界

地图边缘通过"高速公路出口"连接外部世界：

- **外部需求**：外部对本地产品的需求波动（影响 I/C 区）
- **移民**：市民可以通过边界迁入/迁出
- **贸易**：进口/出口资源（电、水、商品）
- **多人预留**：未来其他玩家的城市可在此"外部世界"中作为邻城出现

## 11. 模拟循环（每 Tick）

```
1. TimeSystem.Update(dt)           // 时间推进 + 触发日/月/年事件
2. DemandSystem.Update()           // RCI 需求更新
3. PopulationSystem.Update()       // 人口迁入/迁出/出生/死亡
4. EconomySystem.Update()          // 税收结算 + 预算
5. TrafficSystem.Update()          // 出行矩阵 + 路径分配 + 流量/拥堵
6. UtilitySystem.Update()          // 电力 + 供水覆盖
7. ServiceSystem.Update()          // 服务覆盖 + 效果计算
8. EnvironmentSystem.Update()      // 污染扩散 + 绿地效应
9. LandValueSystem.Update()        // 土地价值更新（交通+服务+环境+邻区）
10. ZoneSystem.Update()            // 密度升级/降级 + 人口/岗位同步
11. ExternalWorld.Update()         // 外部需求 + 移民
```

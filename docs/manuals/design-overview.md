# SimpleCities-LLM 设计概览

> 状态：实施中 | 最后更新：2026-06-02

## 1. 游戏定位

城市规划模拟 · 2D 完全俯视 · 矢量极简主义 · 深度仿真

- **类型**：城市规划模拟（Urban Planning Simulation）
- **视角**：完全俯视（Top-Down）
- **美术风格**：矢量极简主义 — 对标 Mini Metro / Mini Motorways
- **模拟深度**：对标 Cities: Skylines / SimCity
- **交通模拟**：OD 矩阵 + 路径分配，不模拟个体出行者
- **核心抽象**：**不渲染个体建筑**。玩家看到的是分区色块 + 道路网络。所有建筑数据聚合在分区内，如同现实中的城市规划地图——功能分区比单体建筑更重要。
- **网格系统**：8 方向（正交 N/S/E/W + 斜交 NE/NW/SE/SW）
- **时间系统**：基础时钟 1:1 对应现实时间；玩家可加速 ×10/×100/×1000/×10000
- **分区方式**：自由绘制分区形状 + 一键填充道路包围区域
- **市民模拟**：统计层面简化模拟（非独立 Agent）
- **玩家风格**：支持主动管理 / 观察挂机 / 美学创作三种玩法共存
- **失败状态**：可破产但不结束游戏（类似天际线软失败）
- **城市自调节**：城市具备一定自我平衡能力，不会轻易崩溃
- **地形**：Godot 编辑器手工制作
- **外部世界**：支持（为多人游戏和超大地图预留）
- **LLM 含义**：项目完全由 LLM 辅助构建，非游戏内 AI 功能

## 3. 8 方向网格系统

```
        NW   N   NE
         ╲  │  ╱
          ╲ │ ╱
        W ──●── E        ● = 网格单元
          ╱ │ ╲          N/S/E/W  = 正交方向
         ╱  │  ╲         NE/NW/SE/SW = 斜交方向
        SW   S   SE

玩家可沿所有 8 个方向自由铺设道路。
```

## 4. 视觉层级

由于不渲染个体建筑，画面由三层构成：

```
Layer 0: 地形底色（水域 / 绿地 / 不可建造区）
Layer 1: 道路网络（线条 + 交叉口节点）
Layer 2: 分区色块（半透明彩色多边形，R=绿 / C=蓝 / I=黄 / O=紫）
Layer 3: 数据叠加（选中高亮、交通热力图、地价热力图等）
```

> 核心视觉就是一张"城市规划图"——类似现实中市政厅墙上的分区地图。

- **引擎**：Godot 4.6
- **语言**：C# 14.0 / .NET 10.0
- **调试 UI**：ImGui.NET（已有集成）
- **构建方式**：100% LLM 辅助开发

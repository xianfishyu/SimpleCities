    存档 文件与目录 原始文件字节 压缩大小 范围

    配套文件¶

    • .tar.xz.manifest.json.gz：全部成员路径、字节数/SHA256、目录列表和整包哈希。
    • .tar.xz.sha256：对应压缩包SHA256。
    • .verified.json：已完成的归档成员校验记录。
    • 引用目录索引：正式文档/QA入口与原始证据目录的对应关系、输出示例说明。
    • reference-index.json.gz：逐条原引用路径、文件/行号、解析状态、来源文档哈希以及依赖补入关系。
    • git-recovery-manifest.json.gz：3,596个历史Git文件的blob身份及精确换行恢复规则；不覆盖全部未跟踪内容。

    引用包保留被仓库中正式报告、修复记录、规格和QA入口点名的整个运行目录，并递归补入该目录说明/校验脚本引用的本地scratch依赖；保留红灯、失焦和失败尝试，不按结果筛选。原来的源码副本、临时工程及其本地缓存若位于被引用目录内也一并保留，以保证目录完整。未引用的目录只存在于完整包。

    查看或恢复证据¶

    在仓库根目录使用Python 3.11以上：

    # 默认从本目录的引用包恢复指定目录；缺少对应本地包时读取历史Git blob。
python Scripts/QA/scratch_archive.py extract --directory v4-24-20260930
python Scripts/QA/scratch_archive.py extract --directory v4-04-qa --destination D:/EvidenceRestore

# 完整包恢复所有原始文件，包含原本未跟踪的内容。
python Scripts/QA/scratch_archive.py extract --bundle docs/runtime-evidence/road-v4-20261012/complete-scratch-20261009.tar.xz --destination D:/EvidenceRestore

# 独立核验两个存档与Git历史恢复身份。
python Scripts/QA/scratch_archive.py verify --bundle docs/runtime-evidence/road-v4-20261012/complete-scratch-20261009.tar.xz
python Scripts/QA/scratch_archive.py verify --bundle docs/runtime-evidence/road-v4-20261012/referenced-runtime-20261012.tar.xz
python Scripts/QA/scratch_archive.py verify --source git

    恢复到目标根目录的 .scratch/，省略 --destination 则恢复到当前仓库。只恢复指定组时仍核验整包；已有同字节文件跳过，不同内容拒绝覆盖。工具拒绝意外成员、符号链接及越界路径，并补齐 .gdignore，避免Godot导入临时产物。历史脚本可能引用旧入口及不在包内的 .godot 导出文件；旧清单不证明那些二进制仍存在。

    删除与验证边界¶

    此前删除前校验核对了完整包与当时源树的5,863个文件、1,316个目录逐项一致；两个包全部成员的长度/SHA256及真实包的隔离恢复通过。整段清理脚本和独立固定路径删除命令当时均被自动审批拒绝，原因仅为“blocked by policy”。2026-10-12会话归档时，Test-Path -LiteralPath '.scratch' 返回False，Git索引仍无该目录条目；本轮仅确认目录已不存在，没有执行或核实其实际删除方式。清理状态见 cleanup-verification.json。

    当前无需再次删除。以后恢复出该目录而需要清理时，可使用下列命令重新检查归档与目录；只有检查成功才删除明确的工作区路径：

    以后恢复或新采样产生的 .scratch 若需再次删除，应先建立新的完整备份，再运行 verify --bundle ... --check-working-tree；该检查对新文件、改变的字节和链接目录报错，不能拿本次旧快照直接删除后续数据。

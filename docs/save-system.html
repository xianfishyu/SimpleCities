    存档与联合加载¶

    SaveManager 协调命名槽、自动保存、删除确认和场景加载；SaveSlotStore 负责磁盘事务；道路参与者负责业务载荷。完整接口见持久化类参考，本文维护调用顺序、身份与失败边界。

    保存什么¶

    层 当前格式或内容
    保存根 编辑器和导出均使用 user://saves-v4，由 Godot 全局化
    道路文件 <slot>/road_network_v4.json；参与者 SaveFileName 是无扩展名的 road_network_v4
    道路格式 formatFamily=simple-cities-v4、payloadType=road-network、schema 6
    槽容器 manifest.json，formatFamily=simple-cities-v3、schema 1
    业务事实 地图参数、规范 Node/Edge、profile、链点、contentRevision 和 ID watermark
    会话状态 相机、撤销历史、token、查询索引和 Godot 资源不持久化
    模拟摘要 人口、资金、缩略图当前写空值；城市名等摘要不代表模拟已实现

    V3 槽容器与 V4 道路载荷是不同层。源码改名不迁移协议；当前不读取、转换、覆盖或删除 V2/V3 道路保存根。只有道路是正式业务载荷，新增系统须接入同一联合提交协议。

    槽位身份与路径¶

    自动槽固定为 autosave；另存为生成 manual-<GUID N>。内部 ID 使用受限 ASCII 与直接子目录规则，显示名不能参与路径拼接。显示名可重名、含中文和空格，但必须非空白，最多 128 个 Unicode scalar 且最多 512 个 UTF-8 字节。

    根、槽和文件不得通过重解析点或链接逃逸。临时文件、锁和操作目录不列为玩家槽，也不能根据旧 .autosave.staging/.backup 名称清理当前目录。列举分别识别健康、本族损坏、外来和危险占用；一个坏槽不阻断其它槽。

    ListSlots 返回 ID、名称、UTC 时间、城市摘要、可空模拟/缩略图字段、文件表、有效性、错误与警告。列举只验证适用的槽摘要，不等同于完整道路语义加载。

    文件校验¶

    manifest 字段 校验责任
    formatFamily/schemaVersion 严格识别 simple-cities-v3/1
    slotId 与直接槽目录精确匹配
    displayName/timestamp/cityName 受限文本、规范 UTC 时间与城市摘要
    population/funds/thumbnailFile 当前为空；不宣称已生成缩略图或模拟数据
    files 按名称确定排序的对象数组，每项为 name/encodedLength/sha256；不是旧字符串数组

    编码后用真实字节长度和 SHA-256 建 manifest；读取检查字段、类型、重复项、版本、路径、长度与摘要，必须包含道路文件。不能以“manifest 可读”替代业务有效性。

    道路顶层字段为 formatFamily/payloadType/schemaVersion/contentRevision/nextNodeId/nextEdgeId/profileCatalogVersion/map/nodes/edges。地图记录 widthMetres/heightMetres/origin/metresPerUnit/grid/cellSizeMetres，值对应 8×8 km、center、1 米、square-eight 及创建格长。空地图示例的 contentRevision、nextNodeId、nextEdgeId、目录版本均可从 1 起，nodes/edges 为空；示例不构成本轮 codec 运行结果。

    Node 字段为 id/x/y；Edge 为 id/startNodeId/endNodeId/profile/points，points 包含首尾端点。正身份、watermark、实体排序、开放边定向、自环 seam/方向、四类 profile 和容量上限统一遵循道路规范。

    reader 拒绝未知、缺失或重复字段，非法类型/版本、非有限坐标、越界、非法网格方向、悬空端点、内部未建节点交点、重叠、非规范二度连接和非法闭环。既不修补非法载荷，也不把旧 Group 或曲线 DTO 当作当前格式。

    调用与结果¶

    所有启动 API 在主线程返回操作 token，调用方保存 token 并观察相应状态和终态。接口、重载及事件签名见SaveManager。

    参与者注册与场景保存范围是两个条件：SceneStoragePolicy 声明保存根和 RequiredSaveFileNames，选择参与者时只取必需文件集合中的条目。注册成功不表示自动入档；新增业务系统须同时注册、纳入场景必需文件集合，并参加联合预检/提交。

    调用 约定
    Register/Unregister 同实例幂等；活动文件名冲突拒绝；场景退出注销
    StartSave / StartSaveAs 覆盖已有槽 / 创建新手动槽；成功后选择该槽
    StartAutosave 固定自动槽；不改变当前手动槽；繁忙时按协调规则跳过或合并
    StartLoad 进入 network/tools/presentation/current-slot 联合准入
    RequestDeleteSlot 重新列举并取得当前占用身份对应的一次授权，不执行删除
    StartDeleteSlot 消费匹配授权；过期或不匹配返回空 token
    CancelOperation 请求取消；返回 true 不等于已经无后果地完成取消
    HasOperationResult/GetOperationResult 按 token 查询终态；尚未完成时没有结果
    ListSlots/SaveSlotExists 查询槽摘要/存在性，不替代完整 Load
    RequestApplicationQuit 停止准入、取消或等待适用操作，收敛后退出

    状态通过 SaveOperationStateChanged 和 SaveOperationCompleted 送达消费者。结果包括 operationToken/operationKind/targetSlotID/resultKind/finalPhase/committed/warnings/error；终态可能为 Succeeded、SucceededWithWarnings、Failed、Canceled、SkippedBusy、RejectedShuttingDown 或 RejectedSceneClosing。

    展示结果必须同时解释 committed、错误和警告。提交后的观察者或清理异常不能显示为“未改变文件/路网的取消”。确认页取消、关闭视图和运行中取消是三个不同动作。

    保存与删除事务¶

    保存依次完成：主线程捕获不可变 ISaveSnapshot → worker 流式写入本次 staging → 生成和验证 manifest → 获取提交租约 → 按描述符和目录移动发布 → 通知与清理。需要时保留旧槽 backup；发布前失败尝试保留或恢复旧可见槽，发布后清理失败返回已提交警告。

    覆盖与删除都受同根互斥、跨进程根锁和占用身份约束。删除授权绑定槽 ID、UI 列举代际、operation token、占用分类及摘要。UI 用 ArmDeletion(summary) 捕获确认目标；外部入口用 RequestDeleteSlot。列表刷新、场景变化、目录替换或目标变更后必须重新确认，不复用旧授权。

    可识别的本族损坏槽允许诊断和授权删除；外来或危险占用不借通用坏槽入口清除。恢复依据描述符和身份判断，不能无条件删除临时目录。提交前取消保留旧槽和场景；提交后继续磁盘收敛，停止等待不代表事务结束。

    根锁、SHA-256 和临时 backup 解决协作实例、意外损坏与中断恢复，不提供敌对本机进程隔离、来源认证、防回滚或任意硬件损坏恢复。未知占用须诊断；长期备份与认证需另定协议。

    联合加载与退出¶

    1. 捕获场景代际以及 network/tools/presentation 准入，保存当前草稿/选择的恢复边界，阻止新道路写操作。
    2. worker 有界读取并校验 manifest、文件字节和 RoadCodec，构造 PlanLoad 与纯表现准备。捕获后的 reader/snapshot 不再访问可变场景。
    3. 主线程复核场景代际、plan 来源、全部参与者准入及 Godot 资源。预检失败释放准备内容，保留活动路网、历史、工具、表现和当前槽。
    4. 所有 INonThrowingLoadCommitPlan 准备好后，在一次同步调用中交换路网、工具 full reset、表现和当前槽。该区域不 yield，不分配 Godot 资源，不做文件操作，不调用用户回调。
    5. 新 lineage 和空历史随加载结果接管；完成后再通知和清理。此后的异常汇总为警告，不伪称尚未提交。

    这是预检后无异常引用提交的契约，不是任意错误参与者的通用回滚库。IStreamingSaveable 的 CaptureSnapshot/WriteSnapshot、CaptureLoadReader/PrepareLoad、CommitPreparedLoad 分属捕获、准备和提交；单独提交参与者不能代替产品级联合加载。

    场景关闭时停止新准入，取消适用操作并等待已跟踪操作收敛；代际变化使旧结果失效。返回主菜单和退出都经协调入口，不能直接终止进程跳过事务。结束城市不会自动代替玩家保存。

    UI、自动保存与验证¶

    玩家保存/加载入口集中在暂停菜单。覆盖、加载、删除展示目标并确认，按 token 显示阶段、等待、取消、错误与警告。

    AutosaveController 位于 CityMap，默认周期 300 秒，Timer 随场景暂停；离开场景停止调度。它调用 StartAutosave，记录成功、失败、取消及繁忙跳过，不覆盖当前手动槽身份。

    验收覆盖命名/路径、manifest/字节、跨进程锁、描述符恢复、取消边界、过期删除授权、联合预检失败及提交后通知故障。主要入口是 SaveManagerSlotContractTests、SaveManagerManifestVersionTests、SaveOperationCoordinatorTests、PreparedAggregateLoadTests、SceneLoadPreparationTests、描述符/预览验证与 AutosaveContractTests；引擎、导出和磁盘故障范围见验证手册。本次文档整理不刷新原实测日期。

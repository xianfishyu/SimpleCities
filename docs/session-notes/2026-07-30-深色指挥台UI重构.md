## 会话目标

用户希望完成 SimpleCities 的深色指挥台 UI 重构，把 HUD 从早期开发控件改为文档先行、暗色、面向玩家的命令中心。目标包括底部建造停靠栏、可向上滚动的工具托盘、道路工具的中文与行为对齐、目录驱动上下文、调试与系统控制拆分、共享主题字体、640x480 响应式布局、焦点路径、每个 HUD 独立 UIManager，以及完整验证和记录。

## 已完成

- `DESIGN.md` 与相关文档先于实现更新，明确深色指挥台方向、布局边界和 CJK 文本要求。
- HUD 改为底部 `ConstructionDock` 加向上滚动的 `ToolTray`，低分辨率下仍保留可用空间。
- 道路工具收敛为准确的 `Roads` 分类和 `选择铺路拆路` 中文说明，避免旧文案与实际交互错位。
- 建造上下文改为目录驱动，工具内容来自建筑目录，而不是在 HUD 中散落硬编码。
- `DebugPanel` 和 `SystemControls` 拆出独立 UI 区域，调试信息、暂停、帮助和退出控制不再混在建造栏里。
- 共享 `Theme` 与 `SystemFont` 被纳入 UI 路径，保证深色控件、边框、间距和 CJK 字形来源一致。
- 640x480 响应式布局、键鼠和焦点行为经过调整，命令中心在小窗口中保持可读和可操作。
- 每个 HUD 拥有自己的 `UIManager`，避免多个 HUD 实例共享 UI 状态。
- 已补充并通过相关测试，覆盖布局契约、目录上下文、按钮文案、焦点和系统控制等关键行为。

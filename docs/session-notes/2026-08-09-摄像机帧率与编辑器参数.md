## 重要决策

- 缩放平滑采用 `1 - pow(1 - response, delta * referenceFps)`，使相同真实时间内的响应不再随更新频率改变。
- `smoothing` 当前为 `0.25`，`referenceFps` 为 `60`。需要改变缩放手感时调整前者，而不是恢复按帧固定的插值。
- Godot C# 不会将普通 `//` 或 XML 注释显示为 Inspector 参数提示；因此使用英文 `ExportGroup` 和 `ExportSubgroup` 将说明直接呈现在 Inspector 中，同时保留简短英文源码注释，未引入自定义编辑器插件。
- `run/max_fps` 是帧率上限而非保证值；VSync 和显示器刷新率仍可能形成实际限制。
- 键盘平移使用匀速目标的一阶平滑解析更新，避免“乘以 delta 后仍因逐帧插值产生差异”；中键拖拽状态由摄像机事件维护。

    2026-08-13 会话整理：第三代道路系统设计与路线图¶

    作用域：SimpleCities 项目本地会话记录 存放位置：docs/session-notes/ Git 状态：docs/session-notes/ 已被 Git 跟踪；本记录与第三代道路指南、路线图及 V2/V3 接线文档联合提交 工作分支：V2 边界校准已提交到 feat/road-network-v2；V3 文档位于 codex/road-system-v3，两个分支均未配置 upstream

    会话目标¶

    审阅当前道路系统、连续道路存储和存档实现，形成第三代道路系统迭代指南；将一条道路从单位长度碎片重构为结构边界之间的最大连续 Edge，覆盖拐弯、自环、独立环、平行 Edge、自交路径、存档迁移、异步保存/加载和编辑历史；最后把 V2 与 V3 的长期工作项完全分开。

    重要决策¶

    • GraphEdge 表示两个结构边界之间的最大连续道路；转弯和原生几何段边界不自动产生 Node，局部查询通过不持久化的半开 query fragment 保持有界。
    • self-loop 使用固定 topology seam 根化；禁止跨 seam 合并或旋转 geometry 数组。line 仅在公共点 bit 相同、精确 Orient2D == 0 且 DotSign > 0 时合并；full-turn 只接受精确 binary32 +/-Tau。
    • 图邻接以 endpoint-role incidence 表达，自环贡献两个 incidence；平行 Edge 和 self-loop 是合法领域拓扑，模拟层只能定义映射，不能反向禁止。
    • RoadGraphRevision 不可变并结构共享；局部编辑不得深拷贝远端全图。撤销/重做保存有界可逆 delta，不保存完整 JSON 副本。
    • Load 在 Preflight 预建 graph、tool、隐藏 Mesh/RID、surface 和 hit index，并在一次 non-yield commit 中联合交换；关键表现失败只能发生在提交前，提交后只有普通 observer warning。
    • PublishV2、ResolveLegacyState 和 Load 是三个独立事务、token 与结果。Resolve 只改磁盘，不加载、不改 CurrentSlotID；Load 只读磁盘，不移动、归档、升级或回写槽。
    • V2 与 V3 Git 历史按用户要求分开：V2 分支只保存 V2 边界事实；V3 指南、路线图、根层迁移指针、交通模拟接线和本会话记录在新 V3 分支提交。

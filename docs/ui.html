    界面、输入与视觉规范¶

    当前界面是深色城市规划指挥台：以清晰中文、克制的层次和状态反馈支持建造、观察、存储。本文统一维护布局、交互、资源所有权与视觉规则；逐成员说明见UI 类参考。

    组成与所有权¶

    GameHUD 是 CityMap 中的 CanvasLayer。它组合 ConstructionDock、ToolContextPanel、PauseMenu 和 DebugPanel，并持有自己的 UIManager；两个 HUD 的模态栈和面板注册互不共享。ConstructionDock 始终显示，不注册为管理面板；其余三个面板按名称注册。

    HUD 从 RoadToolManager、父 RoadMapScene 和导出 RoadConfig 获得依赖。RoadToolManager 委托唯一场景状态，原始道路指针由 RoadMapScene 处理；界面不建立第二套路网。ContextPanel 解释工具，PauseMenu 承担玩家存储操作，DebugPanel 承担开发指标。

    关键资源为 Scenes/UI/GameHUD.tscn、ConstructionDock.tscn、ConstructionDockButton.tscn、PauseMenu.tscn、RoadsConstructionCategory.tres 和 Themes/ConstructionDockTheme.tres。目录、纹理和工具数据由场景/Resource 持有，不在 C# 中硬编码图标路径。

    建造坞与分类¶

    项目 规则
    根布局 全宽、底部贴边；left/right/bottom offsets 为 0，锚点 left=0、top=1、right=1、bottom=1
    高度 折叠 76px；展开 140px = 64px ToolTray + 76px CategoryBar
    分类按钮 最高 104×76，窄屏缩至 72px 最小宽度，间距 8px；32×32 图标在文字上方
    二级工具 固定 104×64，24×24 图标；ToolList 整组相对全坞居中，不依附当前分类位置
    滚动 ToolScroll 和 CategoryScroll 仅横向滚动，隐藏滚动条且不占高度；超宽二级组保留固定格宽
    选中 一级使用按下底色、琥珀图文和绝对底部 4px 指示条；二级使用底色和图文，无下划线
    焦点 独立 1px 焦点环，选中/悬停不能掩盖键盘焦点

    五个分类始终可用且可聚焦。点击新分类切换目录并展开，点击当前分类折叠/重开，不重建同一菜单；折叠后当前分类仍保持选中和底部指示条。可见性变化通知 GameHUD 更新空间预留。

    分类 ID / 标签 工具或占位
    roads / 道路 城市道路 → Road，说明“拖拽铺设道路。”；道路改造 → RoadUpgrade，说明“选择已有道路并改造类型。”
    zoning / 区域 住宅区、商业区
    facilities / 公共设施 学校、诊所
    transit / 交通 公交站、地铁站
    landscaping / 景观 公园、广场

    道路目录按 SortOrder 只提供上述两项可用工具，动态节点为 RoadToolButton/RoadUpgradeToolButton；Select 和 RoadRemove 通过绑定/程序入口提供。其余分类的 104×64 占位按钮禁用、不可聚焦，提示“尚未开放”；不注册按下处理器，即使强制发 pressed 信号也不能改工具、开模态、注册快捷键或调用玩法目录。

    ConstructionCategoryDefinition 校验身份、名称、空项、工具枚举和重复 ID。缺失或非法数据以禁用交互及诊断降级。ConstructionToolDefinition.Icon 默认可为空，表示待配置数据，不隐式加载占位路径。

    控件与上下文同步¶

    ConstructionDockButton 保留 Godot Button 原生 disabled/toggle、键盘激活、tooltip 和焦点语义。稳定结构为 Presentation(VBoxContainer)/Icon(TextureRect)/Label，加直接子节点 PrimarySelectionIndicator；这些子节点均 MouseFilter.Ignore。

    VisualRole 显式区分 PrimaryCategory 和 SecondaryTool。动态工具与占位项建立同一结构，但二级项始终隐藏指示条。属性 setter、主题变化与绘制同步时优先 disabled，再 selected，再 primary 色；缺语义色时回退字体色，最后 Colors.White。退出时清理节点缓存，未 Ready 时不触碰旧节点。

    道路分类使用同一 Category 资源提供名称/描述，快捷键从 InputBindingManager 实时读取；GameHUD 缓存工具、profile、Config 和格长，避免重复格式化。等待、错误和重试通过 UpdateRoadState 单独更新。

    未来分类令 UsesCatalogContext=false，发送 ContextDisplayChanged(name,false)，ContextPanel 显示分类与未开放提示，隐藏道路配置和快捷键行。此时工具快捷键仍可改变底层工具，但上下文保持当前未来分类；没有快捷键的说明不显示空快捷键行。

    输入与焦点¶

    动作 默认绑定 消费者
    KeyBoard_MoveUp/Left/Down/Right W/A/S/D MainCamera
    tool_select/tool_road/tool_remove/tool_upgrade Q/R/E/T GameHUD → RoadToolManager → RoadMapScene
    edit_undo/edit_redo Z/Y 同一场景历史
    pause_menu Esc GameHUD / 已打开的 PauseMenu

    十一项单键动作由 InputBindingManager.Definitions 生成编辑页，成功重绑或恢复默认后保存到 user://input_bindings.cfg。拒绝重复键、不可用键和纯修饰键；旧配置缺动作时只补不冲突默认键。上下文在下一次 HUD 更新反映绑定，不依赖目录静态 ShortcutHint。F5/F9 不提供保存/加载旁路。

    模态打开时暂停普通工具快捷键。重复当前工具不清草稿；允许切换时清理未提交草稿/选择。历史请求受场景 CanUseHistory 约束，不隐式完成草稿。删除/改造拖选整笔提交、取消和显示重试遵循道路规则。

    暂停绑定先处理道路取消：有可处理交互则取消并消费输入，否则打开菜单。原始 Esc 也可经过工具的 _UnhandledInput 进入同一取消入口；加载准入期间消费取消意图但保持已捕获草稿/选择。

    焦点按五个分类 → 当前可用道路工具 → ContextFocusEntryButton → DebugToggleButton → RoadsCategoryButton 循环，反向对应当前顺序；折叠或未来分类跳过不可用工具。PauseMenu 临时接管焦点，关闭恢复仍有效、可见、可聚焦的先前控件。

    暂停菜单¶

    PauseMenu 是 HUD 私有全屏模态：压入自身 UIManager、记住焦点、暂停 SceneTree；菜单使用 Always 处理。根场景保持可见便于编辑器编排，HUD 实例覆盖 visible=false，普通 C# 场景脚本不替代这一资源配置。

    页面/操作 行为
    打开/继续 打开聚焦“继续游戏”；继续弹出模态并恢复场景，不改变工具、道路或相机
    子页导航 主菜单页暂停动作关闭菜单；设置/存档子页返回或取消对应操作；重绑定监听时输入归捕获
    存档管理 命名手动槽、自动槽、另存、覆盖、加载、删除；按 operation token 显示阶段、等待、取消、提交状态、错误和警告
    确认 展示覆盖/加载/删除目标，默认聚焦“取消”；删除确认绑定占用摘要与列举代际，过期后重取授权
    设置 Master 音量 0–100% 映射 -60–0 dB，静音改变 mute；无 Master 时禁用。音频只在会话内，按键绑定持久化
    返回主菜单 确认后停止新场景存储准入并等待收敛，再进入 Scenes/MainMenu.tscn
    桌面退出 确认后经 SaveManager.RequestApplicationQuit 收敛存储再退出

    结束城市不自动保存；MainMenu“进入城市”加载 CityMap，并不取代项目正式启动场景。存储确认页取消、运行中取消和关闭页面分别处理；提交后警告不能显示成未改变状态。坏本族槽只开放适用删除，外来/危险占用不可借此清除。磁盘协议集中在存档手册。

    模态使用遮暗层与居中面板，main/settings/bindings/confirmation/save-management 视图互斥；main、settings、confirmation 三页内容的基准宽均为 360px，绑定列表在视口内滚动，435×480 时绑定按钮仍至少 132px。它是全屏模态，不是坞内卡片。

    视觉规范¶

    使用低亮度表面、清楚的简体中文/英文/数字和小幅色调变化。地图保持可见，Canvas 色不作为永久覆盖层。共享 HUD 与建造坞使用同一套深色/琥珀含义，建造坞仍拥有局部 Theme，修改它不连带重设 Debug 或 Context。

    字级 字号/字重/行高
    标题 16 / 600 / 20
    坞外按钮 14 / 600 / 18
    正文 14 / 400 / 20
    标签 13 / 500 / 18
    辅助说明 12 / 400 / 16
    等宽数据 12 / 500 / 16

    动效使用短 tween/AnimationPlayer，优先 alpha、position:y、scale 或开关边界的一次布局；不持续动画布局属性。层次通过色调表达；底部坞平直贴边，不添加渐变、重阴影、分类卡片或复制的装饰素材。

    图标与资源¶

    响应式与生命周期¶

    1600×900、640×480、435×480 下，中英文标签均不得裁剪；折叠/展开坞都须全宽贴底且保持固定高度，五个分类在 435px 下仍可见；ContextPanel、DebugPanel 与坞均在视口内且互不重叠。窄屏 ContextPanel 折叠为 44px，展开后内容滚动，长错误和重试入口仍可访问。

    HUD 从实时坞顶部设置 ReservedBottomTop，合并 Ready、视口变化、工具条变化、上下文变化和面板 resize 请求，待容器稳定后再 ApplyResponsiveLayout；Debug 保持左上角。

    同一实例移出再加入场景时须保持幂等：HUD 断开视口、坞、暂停与布局信号，注销自己的面板，清刷新标记，并为自身与四个子组件 RequestReady；坞进入前/退出时 TeardownRuntimeState，释放处理器、动态按钮、字典、依赖和焦点缓存，重置分类为 roads 后重建。不能留下重复响应或旧节点。

    DebugPanel 默认折叠，FPS 约 250ms 更新，折叠时不持续计算展开内容。Node、CanonicalEdge、GeometrySegment、QueryFragment、SelfLoop 来自 presented token 缓存；指针按对应地图吸附并标记结构节点。无表现时显示 --，指标不进入主玩家坞。

    验证与降级¶

    验收覆盖分类/资源合法性、生产图标、布局、正反焦点、模态、按键冲突/持久化、等待/重试、两个 HUD 独立管理器和同实例重复进出；静态与引擎入口见验证手册。故障测试可接受与前提匹配的依赖诊断，正常 CityMap 不应以降级作为健康状态。

    缺工具/道路场景时 HUD 明确降级；缺 Config 时告知使用 fallback；非法分类禁用交互。现有日志中 ToolManager/V4 map 等旧词是原日志文字，不表示恢复了退休类型。本文整合原已接受契约，本次未重新执行布局、焦点或图形验收。

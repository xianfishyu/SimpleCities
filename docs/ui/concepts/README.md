# SimpleCities 建造栏视觉概念

此目录保存用于讨论全宽底部建造栏的 SVG 概念稿。这些文件不是生产 UI 资源，未接入 Godot 场景，也不会改变运行时 Theme。当前生产设计事实以 [`../design-system.md`](../design-system.md) 为准；概念稿只能作为历史讨论输入，不能作为 Godot 资源引用。

## 文件

- `全部建造栏方案总览.svg`：首选打开文件，在 1920×1440 画布中以 2 列 × 3 行统一契约比较当前六套建造栏方案。
- `实心几何分类图标.svg`：使用大块填充几何剪影的五分类方案。
- `线性描边分类图标.svg`：使用统一 2px 描边的五分类方案。
- `克制双色分类图标.svg`：以浅蓝灰主体配合小面积分类强调色的五分类方案。
- `分类图标风格对比.svg`：在相同全宽底栏、按钮尺寸和状态下比较上述三种图标风格。
- `极简浅色建造栏.svg`：暖白色、无分类卡片的极简交通图式底栏。
- `极简深色建造栏.svg`：同等结构的蓝黑色极简底栏。
- `极简深色纵向道路运输线路.svg`：G 方案，保持 E 的蓝黑极简底栏契约，将道路图标改为纵向双线道路、区域图标改为有间距且大小位置错落的地块、交通图标改为三个站点构成的 T 形运输线路；资产条道路示例保持与 E 一致，便于只比较底栏分类图标。
- `极简深色运输枢纽站.svg`：H 方案，与 G 仅有一处差异：在交通图标的 T 字交汇点增加一个小型双圆换乘枢纽站，用于比较中心枢纽是否提升线路语义。
- `极简深色简化运输枢纽.svg`：I 方案，基于 H 移除交通图标左右端点站点圆，保留水平线路、中心双圆枢纽、下行支线和底部站点，用于比较更简化的运输枢纽语义是否仍然清晰。
- `极简深色轻量三站网络.svg`：J 方案，保留 G 的左右与底部三站 T 形运输网络且不添加中心枢纽圆，但缩小站点半径并收紧线路跨度，用于比较更轻量、更紧凑的三站结构是否比 I 更自然。
- `极简深色轻量四站网络.svg`：K 方案，基于 J 在 T 字交汇点增加一个与所有端点完全同尺寸、同样式的普通中心站点，不使用内环、更大半径或特殊颜色/线宽；该中心站明确不是枢纽。
- `交通图标G到K方案对比.svg`：建议在选择交通分类图标时优先打开的中性对比稿，在同一 1600×1000 画布中并排呈现 G/H/I/J/K 的 32×32 放大网格视图与实际 76px 建造栏上下文。
- `极简分类色点建造栏.svg`：使用少量分类色点和短线段的暖白极简底栏。
- `极简建造栏风格对比.svg`：在 1600×900 画布中并排比较三套极简建造栏。

## 分类语义

概念稿借鉴城市建造游戏的信息层级，但不复制专有图标、标志或素材：

1. 道路：道路和车道线。
2. 区域：分区地块网格。
3. 公共设施：市政建筑或方框十字。
4. 交通：公交、站点或站线。
5. 景观：树木和公园地面符号。

G 方案用于和 E 方案单独比较图标语义：道路从横向道路样式旋转为 32×32 内的纵向平行道路与短中心车道线；区域使用四块互相留有间距、尺寸和位置略微错落的地块轮廓，避免规则四宫格；交通使用左右两站横向连接、中央线路向下延伸至第三站的 T 形网络，不绑定公交、地铁或铁路中的单一方式。H 方案保持 G 的画布、底栏、资产条、标签、状态和所有非交通图标不变，仅在 T 字交汇点加入一个克制的小型双圆换乘枢纽站。I 方案继续保持 H 的非交通视觉与布局细节，只删除左右端点站点圆，保留水平线路、中心双圆枢纽、下行支线和底部站点。J 方案回到 G 的三站 T 网络平衡结构，但将端点圆半径从 2.5 缩小到 2.0，并把左右站点收至 `(8,10)`、`(24,10)`、底部站点收至 `(16,23)`，以测试减轻视觉重量和跨度后是否仍能避免中心枢纽语义。K 方案沿用 J 的轻量路径和三个端点，再在 `(16,10)` 交汇点放置第四个半径同为 2.0 的普通站点；中心圆与端点完全一致，明确不是换乘枢纽或更高等级中心节点。

## 查看顺序

建议首先打开 `全部建造栏方案总览.svg` 进行六方案直接扫描；若要专门选择交通分类图标，优先打开 `交通图标G到K方案对比.svg` 同屏比较 G/H/I/J/K；随后再打开 `极简建造栏风格对比.svg` 和 `分类图标风格对比.svg`，最后以 100% 比例检查各独立方案。重点比较小尺寸可读性、选中和禁用状态是否不依赖单一颜色，以及图标放在中文标签上方时是否保持一致。

当前生产设计系统记录在 [`../design-system.md`](../design-system.md)。部分概念稿刻意使用冷青蓝选中态；生产实现只采用其中被设计系统明确收录的 K dock 例外，概念 SVG 本身仍是非生产资料。
